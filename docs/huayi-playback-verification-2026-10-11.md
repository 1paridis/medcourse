# 华医网逐视频播放验证

验证日期：2026-10-11（Asia/Shanghai）。

## 实现行为

- 河南平台与华医网使用同一账号串行调度规则：默认全局并发为 1，同一网站账号始终只播放一节。按课程顺序及章节编号继续，课程不会因导入时间相同而交叉播放。
- 华医网从所属项目目录获取章节原始链接，校验章节、域名及播放器页；支持实际跳转的 `course_ware_polyv.aspx`，不拼接媒体鉴权地址。
- 平台已完成或待考试的视频跳过；按目录分类排除互动病例演练。
- 读取 HTML5 媒体及内嵌媒体的真实时间，使用平台默认速度和续播位置。后台浏览器静音；不修改播放时间、平台学时或考试结果。
- 验证提示暂停当前媒体并等待人工处理；播放器故障、登录失效或进程异常均暂停后续队列，人工继续时重试当前视频。
- 自然结束后通过所属课程目录确认目标章节状态，再继续下一视频；平台未确认时要求人工检查。
- 登录保存包含华医网域的 Cookie、localStorage 与 sessionStorage，按账号独立保存；会话文件权限为 0600，恢复时排除过期 Cookie。

## 验证结果

`npm test`：66 项通过。涵盖目录及链接校验、内嵌媒体、错误章节、侧栏无关登录、验证提示、完成确认、账号串行、跨课程顺序、暂停继续、异常退出、会话隔离及恢复。`npm run build` 成功；`git diff --check` 通过。

真实华医网后台任务进程：使用已保存登录的隔离临时资料，从“基于证据的妇科中西医协同治疗”项目目录打开第 2 节“从中医论治卵巢功能减退”，正常跳转到保利威播放页。未改时间或速度，平台自动恢复到 1451 秒（24:11），随后实际播放器读数增长到 1455.625、1460.632 秒；暂停快照为 1460.681 秒，任务正常返回 `paused`。实际媒体时长为 2938.24 秒，速度为 1。

真实验证只进行了短时间续播和暂停；完整视频自然结束后的完成确认与下一节切换由自动化测试覆盖，未通过跳转时间或伪造完成状态缩短学习过程。考试和互动病例没有操作。

本地应用界面联调：重启服务载入更新后，“开始本站学习”正确跳过第 1 节待考试和第 12 节病例；第 2 节为运行中，第 3 节及后续视频保持排队。点击“暂停本站学习”后，第 2 节显示已暂停并保留 24:42 / 48:58 的实际进度，开始按钮恢复可用，后续队列一并暂停。验证结束时本站没有继续后台播放。
