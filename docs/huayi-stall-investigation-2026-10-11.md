# 华医网停止排查与浏览器开关

验证日期：2026-10-11（Asia/Shanghai）。

## 实际原因

历史任务“从中医论治卵巢功能减退”连续三次因 60 秒进度未增长退出，最后记录为 2920.439 / 2938.197 秒。隔离临时浏览器复现后，媒体实际从 2920 秒正常续播至 2936.363 秒，随后暂停；缓冲已覆盖媒体末尾，媒体没有结束或错误。页面出现“温馨提示：您辛苦了，记得适当休息眼睛，让学习更高效！／好的，知道了”。

网站的签到弹窗位于 `.study_diaog` / `.sign-in-menu`，确认按钮为 `.btn_sign`。文案没有原识别规则中的“签到、打卡、人脸”等关键词，因此旧程序漏识别，并在 60 秒后误报进度停滞。浏览器缓存中的网站脚本同样表明，这个随机提示会主动暂停媒体，人工确认后恢复播放并提交签到。

真实检查开始时已保存的会话跳转登录页，用户重新登录后继续验证。登录失效是本次检查遇到的独立问题，历史三次停止日志均为进度停滞。

## 修改

- 识别可见的华医网签到按钮及其父容器，隐藏提示不阻塞。签到期间不恢复媒体、不进入下一视频，显示等待人工验证，且不计入 60 秒停滞时限。
- 可见浏览器提示用户在当前播放窗口确认；无头模式提示暂停、开启“显示浏览器”后重新开始。人工处理后继续正常监控，不代点签到或修改网站计时。
- 两个网站均提供“无头模式／显示浏览器”开关，按用户和网站账号保存，应用于新启动的任务及独立课程名称读取。人工登录始终显示窗口。
- 数据库升级至 v4，旧账号默认无头模式；升级前自动备份，保留课程、任务、进度及登录资料。
- 修正华医网侧栏状态读取位置，结束时目录已确认的“待考试”不会被旧侧栏的“学习中”覆盖。

## 验证

- 82 项测试通过，包含开关 API、用户/网站隔离、v3 升级及持久化、工作进程配置传递、无头名称读取登录提示、可见及隐藏签到识别、签到阻止自动恢复、完成状态不回退。
- `npm run build`、`git diff --check` 通过。
- 修复后的真实华医网任务使用可见浏览器正常续播，第 2 节自然结束于 2938.197 / 2938.197 秒，课程目录确认“待考试”。本次可见播放未再次触发随机签到；等待及人工恢复由自动化测试覆盖。
- 管理界面核实河南平台默认无头、华医网显示浏览器，设置分别保存。只运行当前第 2 节验证；随后正常刷新课程目录，第 2 节显示“待考试”，后续视频未启动。考试及互动病例未操作。
