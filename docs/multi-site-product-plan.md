## 3. 用户流程

1. 点击“添加用户”，填写用户名称或备注，例如“张医生”。
2. 保存后进入“选择学习网站”，以卡片展示河南平台与华医网，可多选。
3. 点击“保存学习网站”，建立用户与各网站的绑定，不要求填写课程或链接。
4. 在用户详情中点击网站卡片，进入该用户的“网站设置”。
5. 点击“添加课程”，粘贴学习链接；自动读取网页课程名称，成功后保存为独立课程记录。
6. 可继续添加第二门、第三门课程；每门课单独查看、编辑或移除。
7. 河南平台可针对选定课程使用既有登录、读取视频列表和播放能力；华医网本期只管理手动填写的课程资料。

用户可以先绑定网站，之后再添加课程。网站尚无课程时显示“还没有添加课程”和“添加课程”按钮，不阻止绑定完成。

取消网站设置时保留已创建用户。重复选择网站不重复创建账号。取消选中已有绑定不直接删除数据，应通过单独的移除操作确认，避免课程被误删。

网站选择与已绑定网站切换都采用卡片。卡片展示网站名称、功能说明、选中状态；绑定后显示当前用户在本站的课程数量及“网站设置”入口。

“添加课程”表单：

- 课程名称：从网页自动读取，无需填写；拒绝登录页或网站通用标题，读取失败不创建课程。
- 学习链接：必填，填写实际课程或视频学习页面链接，不能填写网站首页。

河南平台的课程详情展示该课程的视频任务、进度和记录；华医网展示手动填写的课程资料，不显示未实现的登录状态、自动章节列表或播放进度，也不提供人工登录、导入、开始和暂停按钮。

河南平台网站设置中的“登录本站”固定打开网站首页，不沿用上次保存登录时的课程地址；课程行的“进入课程登录”打开该课程的学习链接。

用户切换网站后只查看该用户在对应网站下的课程；不同用户即使选择同一网站、填写同一链接，仍有独立课程记录与学习数据。

## 5. 课程与链接规则

- 一个网站账号下可新增多条课程记录，每条课程有独立 ID、名称和学习链接。
- 绑定网站不需要课程链接；添加或编辑具体课程时才校验必填字段。
- 链接保存时检查非空、格式、HTTPS 协议与基础网站归属，并拒绝已知网站首页；华医网本期不做子域枚举、跳转验证或在线可访问性探测。
- 基础 URL 校验不表示确认页面可访问或可播放；华医网保存后显示“课程已保存”，不显示“验证通过”。
- 保留 URL 中定位课程的路径、查询参数与 hash，不擅自拼接河南章节路由或删除参数。
- 同一用户、同一网站内重复提交完全相同的链接时提示“该课程已添加”，不重复创建；不同用户或不同网站的记录不共用。
- 课程标题不作为唯一标识，同名但链接不同的课程可以并存。
- 河南平台明确读取某门课程的视频列表时，读取结果和新任务归属于该课程，不能归入账号中另一门课程。
- 修改课程名称可以保留原课程 ID；修改已有任务的学习链接时，保留旧课程及任务历史，将新链接作为新课程保存，避免历史进度与新内容混用。尚无任务的课程可直接修改链接。
- “保存登录”只保存账号会话和相关页面信息，不静默覆盖其他课程的学习链接或更改任务归属。
- 移除课程采用归档方式，先停止该课程的活动任务并确认；保留历史记录，归档课程不再参与本站后续批量启动。

河南平台原有“开始本站学习 / 暂停本站学习”继续作用于该网站账号，覆盖其已加入视频列表的未归档课程。单纯新增课程资料不自动创建或启动视频任务。选择具体课程读取列表时仍沿用账号互斥规则。

## 6. 数据结构

| 实体 | 核心字段 | 说明 |
| --- | --- | --- |
| User | id、name、createdAt | 本地学习者 |
| Platform | id、name、entryUrl、capabilities | 全局网站注册表，不保存个人课程 |
| Account | 现有字段 + userId、platformId | 当前用户在某网站的独立账号与设置归属 |
| Course | id、accountId、name、learningUrl、createdAt、updatedAt、archivedAt | 用户在该网站下的一门课程，Account 与 Course 为一对多 |
| Job | 保留现有字段 + courseId | 视频任务关联具体课程，继续保留 accountId 供现有调度使用 |

移除之前“一份 Account 保存一个 learningUrl”的设计，学习链接存入 Course。现有 Account.courseUrl 暂时保留为河南执行兼容字段，不代表该账号全部课程，也不作为多课程的唯一数据来源。

添加 `UNIQUE(userId, platformId)`，一个用户在同一网站有一份绑定、多门课程；Account 的 platformId 不可直接更换。

Course.accountId 不允许直接跨用户或跨网站修改。创建任务时服务端从 Course 查出 Account 与 Platform，保证 Job.accountId 和 Course.accountId 一致；不能依赖客户端自行声明归属。课程、任务和日志的查询及修改均按所属用户与网站限定范围。

浏览器登录资料继续按 `profiles/{accountId}` 隔离，同一用户同一网站下的多门课程共用该网站账号的登录资料；不同用户、不同网站不共用。

## 7. 接口与实现边界

建议接口：

- `GET /api/platforms`：获取网站卡片资料与能力。
- `POST /api/users`：添加用户。
- `POST /api/users/:id/accounts`：批量绑定所选网站，只提交 platformIds，不要求课程链接。
- `GET /api/accounts/:id/courses`：获取该用户在本站的课程列表。
- `POST /api/accounts/:id/courses`：添加一门课程，只提交 learningUrl；服务端读取网页中的课程名称后保存。
- `PATCH /api/courses/:id`：编辑课程资料，处理历史任务与链接变更约束。
- `POST /api/courses/:id/archive`：确认后归档课程，保留历史。
- `GET /api/overview`：增加 users、platforms、courses，提供完整归属关系。

河南平台创建登录或课程读取任务时可携带 courseId，由服务端解析课程链接及账号，不依赖 Account.courseUrl 选择多门课程中的目标。保存登录不改变已关联课程；读取视频列表后的任务必须写入对应 courseId。

服务端将课程资料管理与学习执行能力分开。华医网允许增删改查课程资料，执行类请求明确返回“该网站学习功能尚未接入”，不创建执行任务或启动浏览器。

本期保留河南实现，通过 platformId 分发和 capabilities 判断限定执行范围，不要求完成通用播放器重构、华医网适配器或跨域会话结构扩展。

调度继续沿用按 Account 互斥及全局并发规则，华医网不生成执行任务。课程筛选、列表读取、任务归属和归档过滤需要与多课程模型同步调整。

## 8. 旧数据迁移

1. 停止服务，备份数据库与浏览器资料。
2. 每个旧 Account 创建同名 User，回填河南 platformId 与 userId，不按名称自动合并用户。
3. 保留原 Account ID、Job ID、任务、进度、日志及浏览器目录。
4. 按每个账号已有播放任务的课程 URL 分组，创建 Course，使用原 courseTitle 填充名称，将视频任务关联到相应 courseId；同账号中原有多门课程分别保留。
5. 旧 Account.courseUrl 如符合既有课程页面规则且尚无对应课程，可补建 Course；仅有首页地址时不创建虚假的课程，详情提示添加课程。历史服务任务保留原记录，可不关联 courseId。
6. 在事务中迁移并记录 schema version，重复启动不重复创建用户或课程。迁移失败回滚并报错。
7. 迁移不自动启动任务；退回旧版时恢复迁移前备份。

## 9. 实施顺序与本期验收

实施顺序：用户与网站注册表 → 多课程数据结构和迁移 → 网站卡片及用户的网站设置 → 课程管理 → 河南现有任务与课程关联 → 能力限制和回归验证。

本期验收：

- 新用户可通过网站卡片选择一个或多个网站，未添加课程也能完成绑定。
- 网站卡片不再显示必填视频链接，链接在“网站设置 → 添加课程”中填写。
- 同一用户在一个网站下可添加多门课程，每门课有独立名称、链接和 ID，刷新、重启后保留。
- 两个用户使用同一网站时各有自己的课程；同一用户在不同网站下的课程互不混入。
- 同名不同链接可保存；同一账号重复添加相同链接得到明确提示。
- 华医网可手动管理多门课程资料，不要求登录、自动导入或播放验证；执行 API 被正确限制。
- 河南平台选择不同课程读取视频列表，任务归属正确；重复读取不覆盖其他课程或产生重复任务。
- 修改课程资料不篡改其他课程与历史任务；归档课程保留记录并退出后续批量启动。
- 旧账号已有多门课程可迁移并分别显示，登录资料、任务、进度和日志保留，现有河南流程通过回归验证。

验证以类型检查、已有服务端测试、多课程迁移与归属测试、华医网执行能力限制，以及用户创建/卡片选择/课程管理界面检查为主。

## 10. 后续调整：华医网首页人工登录测试

按用户测试需求，新增基础“登录本站”入口，仅打开华医网首页的可见浏览器，完成手动测试后点击“结束登录测试”。网站登录能力与课程执行能力分开，华医网允许首页登录任务，但仍拒绝检查课程、读取列表及播放任务。

## 11. 添加课程自动读取名称

添加表单只显示学习链接。已有人工登录窗口时，复用该账号的浏览器会话，在目标课程已打开时直接读取其标题；否则在同一会话打开课程页。没有活动任务时，打开该账号的课程读取窗口；需要登录时由用户人工完成。读取仅提取名称，不导入章节、不操作视频或考试。读取期间占用账号及浏览器并发名额，其他学习任务不会同时打开该账号资料目录。

名称优先取课程页的主标题，拒绝登录页、其他课程、网站通用标题及不可靠名称。获取成功才写入课程记录；失败在表单内提示，可修改链接后重试。编辑已有课程仍可手动改名，历史保留规则不变。
