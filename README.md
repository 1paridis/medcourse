# MedCourse

MedCourse 是河南继续医学教育平台的本地课程播放管理工具。你可以在同一界面管理多个学习账号，登录平台、添加课程视频列表、开始或暂停播放，并查看每个视频的进度和平台状态。

项目以模拟人工观看视频为核心：视频按课程列表顺序自然播放，使用平台默认速度并静音。进度采样读取当前页面播放器属性，不刷新页面或主动调用平台进度接口。打卡提示触发时会保存进度、暂停并重新打开当前视频。登录验证、考试和身份验证需要你在平台上手动完成；学时和课程完成情况以平台记录为准。

## 第一次使用

### 1. 准备运行环境

电脑需要安装 Node.js 24 或更高版本，以及 npm 10 或更高版本。人工登录会打开浏览器窗口，因此需要在有图形桌面的电脑上运行。

以下命令均在 MedCourse 文件夹中执行。

### 2. 安装并准备程序

```bash
npm ci
cp .env.example .env
npm run browser:install
npm run build
```

如果文件夹里已经有 `.env`，跳过复制步骤，保留已有设置。首次安装需要联网下载程序依赖和浏览器，完成后再启动。

### 3. 启动并打开管理界面

```bash
npm start
```

在浏览器中打开 [MedCourse 管理界面](http://127.0.0.1:3000)。运行期间保持启动程序的终端窗口打开。

以后使用时，在 MedCourse 文件夹中执行 `npm start` 即可，无需重复安装。

## 添加账号并登录

1. 在管理界面添加账号，填写便于识别的“账号名称”，例如“学习账号 A”。“课程地址”可填写平台首页或目标课程地址。
2. 在该账号卡片上点击“人工登录”，等待浏览器窗口打开。
3. 在打开的窗口中登录平台，完成验证码等验证，然后进入想学习的课程播放页。
4. 回到 MedCourse 管理界面，在“任务记录”中找到本次人工登录任务，点击“保存登录”。程序会保存登录状态和当前课程地址，并关闭登录窗口。
5. 如需检查登录是否可用，点击账号卡片上的“无头检查”，再查看对应任务的“日志”。检查时不会显示浏览器窗口。

账号名称只是本地备注，账号密码需要在平台登录页面输入。“登录状态已保存”表示登录资料已保存，登录是否仍然有效需要通过页面检查或实际打开课程确认。

## 添加课程视频并开始播放

1. 确认已在目标课程播放页完成“保存登录”。
2. 点击账号卡片上的“添加播放列表”，等待课程视频出现在“视频任务”列表中。
3. 查看视频标题和平台状态，确认是需要学习的课程。
4. 点击账号卡片上的“开始”。该账号未完成的视频会按列表顺序排队，每次播放一个视频。

添加播放列表本身不会开始视频播放。重复添加同一课程的列表会更新标题和平台状态，并保留已有任务与播放进度。

当前支持平台专业课和公需课的课程播放页。视频播放结束后，程序还会等待平台确认当前视频已完成；确认成功后才继续下一个视频。

平台状态“待考试”表示该视频的学习已结束，可以继续下一视频；考试仍需人工完成，平台状态保留为“待考试”。再次启动时，已由平台确认学完的视频会直接结束播放任务，保留已记录的进度，继续未完成视频。

播放使用无头浏览器在后台运行，不打开播放窗口；人工登录仍会打开可见窗口。平台弹出打卡提示时，程序记录触发事件、保存实际进度、暂停并关闭浏览器，再以无头模式重新打开同一视频，沿用平台保存的进度继续播放。同一账号的后续视频保持排队，重开当前视频不启动下一章节。最近一分钟内最多自动重启五次，第六次请求会停止重试并显示“等待人工验证”，管理页面会弹出提醒并持续显示“自动重试已达上限”警告及对应账号、视频和处理方式；身份验证也会等待人工处理。需要人工验证时，先点击账号上的“暂停”，再通过“人工登录”进入课程处理验证，点击“保存登录”后再点击“开始”继续播放。

点击视频任务的“查看”可查看验证事件日志。每次事件包含验证类型、触发时间、章节标识、实际播放器进度、平台状态、事件标识及采取的操作。日志分别记录重开页面、再次触发验证、进度重新增长，以及重启失败或被手动暂停的结果。重开后的进度增长只表示播放器恢复，不代表平台已确认打卡或课程完成。

如需添加另一门课程，先暂停该账号的播放，再通过“人工登录”进入另一门课程的播放页，点击“保存登录”后添加播放列表。“开始”会将该账号所有已添加且未完成的视频排队。

## 暂停、继续和退出

- **暂停播放：**点击账号卡片上的“暂停”。当前视频和该账号排队中的视频都会暂停，已记录的进度会保留。
- **继续播放：**点击同一账号上的“开始”，继续处理未完成的视频。实际从哪里继续播放，以平台当前保存的进度为准。
- **退出程序：**建议先暂停正在播放的账号，再回到启动程序的终端按 `Ctrl+C`。
- **再次使用：**运行 `npm start`，打开管理界面，然后点击需要继续学习的账号上的“开始”。

如果程序意外关闭，重新启动后，未结束的运行任务会显示为“已中断”。此前记录的进度会保留，点击账号上的“开始”可重新排队。

## 查看进度和任务状态

“视频任务”列表显示每个视频的播放进度、播放器状态和平台状态。正常播放时，每 5 秒读取一次当前页面的播放器属性；视频结束或报错通过播放器事件及时触发检查，暂停或停止时保存实际进度。结束后若平台尚未确认完成，间隔 15 秒再读取页面完成状态，最多等待 30 秒。采样本身不刷新页面或向平台发起额外 HTTP 请求，平台播放器原有的学时上报照常运行。

界面可见时大约每两秒刷新本地记录，切到后台后停止自动刷新，也可以按账号筛选查看。界面刷新不会重新读取平台播放器，进度以显示的采样时间为准。

| 状态 | 含义与操作 |
| --- | --- |
| 待启动 | 已添加视频，点击账号上的“开始”即可排队 |
| 排队中 | 正在等待播放名额，无需重复点击开始 |
| 运行中 | 程序正在处理该视频，可查看播放进度 |
| 等待人工验证 | 先暂停，再通过“人工登录”完成验证，保存登录后点击“开始” |
| 已暂停 | 播放已暂停，点击账号上的“开始”可继续 |
| 需要处理 | 播放或平台确认遇到问题，需要先人工检查 |
| 已结束 | 该任务已结束；学时与课程完成情况仍以平台记录为准 |
| 失败 / 已中断 / 已停止 | 查看原因并处理后，点击账号上的“开始”重新排队 |

尚未读取到视频时间或时长时，进度会显示“未知”。本地播放进度用于帮助查看播放情况，不等同于平台累计学时。

“任务记录”用于查看人工登录、页面检查和播放列表读取的结果。点击对应任务的“日志”，可查看执行过程和错误信息。

## 使用多个账号

每个账号分别保存登录资料和课程任务。按“添加账号 → 人工登录 → 保存登录 → 添加播放列表”的步骤为其他账号设置即可。

默认全局同时运行一个任务，其他任务会等待空闲名额。同一个账号每次只能进行一项操作，例如登录、读取播放列表或播放视频；需要重新登录时，请先暂停该账号播放。

如果有明确的多账号同时播放需求，可按下方说明调整同时运行的任务数量。同一个账号仍然每次只播放一个视频。

## 常见问题

### 出现“需要处理”怎么办？

程序会暂停该账号的视频队列并保留进度。先查看视频状态和相关提示，然后：

1. 点击该账号的“人工登录”。
2. 在浏览器窗口中检查课程页面，完成登录、验证码或其他平台要求的人工操作；如播放器报错，确认页面能正常播放。
3. 进入目标课程播放页，回到管理界面点击“保存登录”。
4. 点击账号卡片上的“开始”，继续未完成的视频。

播放器错误、播放进度持续 60 秒未增长、要求重新登录或前置学习，或视频结束后平台未明确确认完成，都可能需要人工处理。打卡提示会先自动暂停并以无头模式重开，短时间重复触发超过上限时等待人工操作；身份验证直接等待人工操作。请先暂停该账号，再通过“人工登录”处理，保存登录后点击“开始”。等待人工验证的时间不计入 60 秒停滞时限。

### “人工登录”或“添加播放列表”按钮不可用怎么办？

先检查该账号是否有正在运行的任务。有视频在播放时，点击“暂停”；其他任务正在执行时，等待其结束，或在“任务记录”中点击“停止”。“添加播放列表”还需要先完成“保存登录”。

### 登录状态已保存，为什么仍然要求登录？

平台登录可能已经过期。重新执行“人工登录”，在平台完成登录并进入课程播放页后，再点击“保存登录”。

### 播放列表为空或读取失败怎么办？

通过“人工登录”确认当前页面是目标课程的播放页，并能看到视频列表，然后保存登录并重新添加播放列表。若平台页面已变化，可能需要更新程序后再使用。

### 浏览器无法打开怎么办？

确认已经执行 `npm run browser:install`，且电脑有可用的图形桌面。如果修改过浏览器缓存位置，请使用当前设置重新执行安装命令。

### 管理界面打不开怎么办？

确认 `npm start` 的终端仍在运行，并查看终端是否出现错误。默认地址是 [http://127.0.0.1:3000](http://127.0.0.1:3000)；修改过端口时，请使用新端口。若提示端口被占用，可调整下方的 `API_PORT`，然后重新启动。

同一个数据目录只能运行一个 MedCourse 程序。如果提示已有实例正在运行，请先检查并关闭其他启动窗口。

## 按需调整设置

一般使用默认设置即可。需要调整时，用文本编辑器打开 MedCourse 文件夹中的 `.env`，修改后退出并重新启动程序。

| 设置 | 默认值 | 何时修改 |
| --- | --- | --- |
| `API_PORT` | `3000` | 默认端口被占用时，换一个 1～65535 之间的可用端口；访问地址也要随之修改 |
| `MAX_CONCURRENCY` | `1` | 需要多个账号同时运行时，可设置为 1～8；人工登录等操作也占用运行名额 |
| `DATA_DIR` | `./data` | 需要把账号资料和进度存放到其他位置时修改；切换到空目录后不会显示原有资料 |
| `BROWSER_CHANNEL` | `chromium` | 默认浏览器有播放兼容问题时，可尝试 `chrome` 或 `msedge`，对应浏览器需提前安装 |
| `PLAYWRIGHT_BROWSERS_PATH` | 数据目录下的 `browsers` 文件夹 | 需要更改浏览器下载位置时设置，修改后重新执行 `npm run browser:install` |

设置中的相对路径以 MedCourse 文件夹为基准。调整并发数量前，确认电脑资源和网络能够支持多个账号同时运行。

## 保存和备份资料

账号信息、课程任务、进度、日志和浏览器登录资料默认保存在 MedCourse 文件夹中的 `data/` 目录。关闭程序后复制该目录，即可备份；恢复时也应先关闭程序，再放回同一位置。如果修改了 `DATA_DIR`，备份对应的目录。

登录资料包含会话信息，请将备份保存在自己控制的位置。保留数据目录即可在下次启动时继续使用已有账号和任务。
