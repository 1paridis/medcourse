# MedCourse

MedCourse 是本地医学教育学习管理工具。你可以添加多位学习用户，通过网站卡片选择学习网站，再到每位用户的网站设置中管理多门课程。用户、网站账号、课程和任务分别保存，切换网站不会混用资料。

河南继续医学教育平台和华医网均支持人工登录、课程视频列表读取、逐视频播放与进度记录；华医网互动病例演练会排除，考试仍需人工完成。

项目以模拟人工观看视频为核心：视频按课程列表顺序自然播放，使用平台默认速度并静音。进度采样读取当前页面播放器属性，不刷新页面或主动调用平台进度接口。打卡提示触发时会保存进度、暂停并重新打开当前视频。登录验证、考试和身份验证需要你在平台上手动完成；学时和课程完成情况以平台记录为准。

## 第一次使用

### 1. 准备运行环境

电脑需要安装 Node.js 24 或更高版本，以及 npm 10 或更高版本。人工登录会打开浏览器窗口，因此需要在有图形桌面的电脑上运行。

以下命令均在 MedCourse 文件夹中执行。

### 2. 安装并准备程序

```bash
npm ci
cp .env.example .env
npm run browser:install
npm run build
```

如果文件夹里已经有 `.env`，跳过复制步骤，保留已有设置。首次安装需要联网下载程序依赖和浏览器，完成后再启动。

### 3. 启动并打开管理界面

```bash
npm start
```

在浏览器中打开 [MedCourse 管理界面](http://127.0.0.1:3000)。运行期间保持启动程序的终端窗口打开。

以后使用时，在 MedCourse 文件夹中执行 `npm start` 即可，无需重复安装。

## 添加用户、选择网站与管理课程

1. 点击“添加用户”，填写便于识别的用户名称，例如“张医生”。
2. 保存后通过卡片选择河南继续医学教育平台、华医网，或同时选择两个网站。选择网站时无需填写视频链接，也可以稍后设置。
3. 在用户详情中点击网站卡片，进入“网站设置”。每位用户在同一网站下都有自己的课程列表。
4. 点击“添加课程”，只需粘贴实际课程或视频学习页面的 HTTPS 链接，课程名称自动从网页读取。不要填写网站首页。如需登录，请在打开的课程窗口完成人工登录；读取成功后才保存课程。
5. 重复添加即可管理多门课。课程可同名，但同一个网站账号不能重复添加完全相同的学习链接。

华医网在网站设置中点击“登录本站”打开首页，登录成功后会自动记录，无需手动保存；完成验证后关闭登录窗口即可。每门课程共用当前用户在本站的浏览器资料，课程行不再提供登录或登录检查。课程行点击“读取视频列表”会读取目录标题、章节、时长、已学时长和平台状态，结果保存到该课程下。支持 `https://cme28.91huayi.com/pages/course.aspx?cid=…` 这类项目详情链接。待考试的章节标为学习已完成，互动病例演练显示为已排除；读取不会进入视频、病例或考试，重复读取会更新目录进度且不重复添加章节。

在课程行点击“编辑”可修改资料。如果课程已有历史任务，更换学习链接会保存成新课程，原课程与历史任务保留。“移除”会停止该课程的活动任务，归档课程并保留历史；勾选“显示已移除课程”可查看。已移除课程不会再次加入本站学习队列。

已有用户可以通过“管理学习网站”增加另一个网站。切换网站只切换显示范围，不自动开始或暂停任务。移除网站或用户会另行确认，并要求先停止活动任务；课程、任务和日志将删除，浏览器资料仍保留在本机。

## 网站统一人工登录

1. 在用户的网站设置中点击“登录本站”，固定打开该网站首页。
2. 在打开的窗口中人工登录，完成平台要求的验证。河南平台可继续进入目标课程。
3. 登录成功后，MedCourse 自动记录本站会话，“任务记录”显示“登录已自动记录”。可继续处理课程验证，完成后关闭登录窗口，再开始本站学习。无需点击保存。
4. 在课程行点击“读取视频列表”。如果登录失效，回到网站设置重新登录即可，无需为每门课程单独登录。

用户名称只是本地备注，账号密码在平台登录页面输入。一个用户在一个网站下的多门课程共用该网站账号的登录资料，不同用户或网站分别保存。“登录资料已保存”不等于确认登录仍然有效。自动记录不会覆盖已填写的课程链接。程序仅在页面显示已登录的账号区域或退出入口后保存，不会将未登录的首页当成成功；窗口打开期间会持续更新会话。

## 添加课程视频并开始播放

1. 确认该用户的目标网站账号已完成人工登录，状态已自动记录，并关闭登录窗口。
2. 在目标课程行点击“读取视频列表”，等待该课程的视频出现在“视频列表”中。
3. 查看视频标题和平台状态，确认是需要学习的课程。
4. 点击网站设置中的“开始本站学习”。本站已读取的未移除课程按添加顺序学习，每门课程内部按目录视频顺序逐个播放；当前课程的全部待学视频完成后，才进入下一门课程。已完成的视频和已排除的内容自动跳过。可按课程筛选查看，筛选不改变启动范围。

视频列表也按相同的课程及视频顺序显示，已完成的视频保留在原位置。暂停、停止、错误或人工验证不会跳过当前未完成的视频或课程；继续时仍从它恢复。

读取视频列表本身不会开始视频播放。重复添加同一课程的列表会更新标题和平台状态，并保留已有任务与播放进度。

河南平台支持专业课和公需课的课程播放页；华医网支持项目详情页中的视频章节，包括内嵌播放器。两个网站都先按课程添加顺序，再按课程内的视频顺序播放，同一网站账号始终只播放一个视频；视频自然结束且平台确认学习完成后，才继续下一个视频。默认全局并发为 1，两个网站的任务也逐个执行。

平台状态“待考试”表示该视频的学习已结束，可以继续下一视频；考试仍需人工完成，平台状态保留为“待考试”。再次启动时，已由平台确认学完的视频会直接结束播放任务，保留已记录的进度，继续未完成视频。

播放使用无头浏览器在后台运行，不打开播放窗口；人工登录仍会打开可见窗口。河南平台弹出打卡提示时，程序记录触发事件、保存实际进度、暂停并关闭浏览器，再以无头模式重新打开同一视频，沿用平台保存的进度继续播放。同一账号的后续视频保持排队，重开当前视频不启动下一章节。最近一分钟内最多自动重启五次，第六次请求会停止重试并显示“等待人工验证”，管理页面会弹出提醒并持续显示“自动重试已达上限”警告及对应账号、视频和处理方式；身份验证也会等待人工处理。需要人工验证时，先点击账号上的“暂停本站学习”，再通过网站设置的“登录本站”进入网站，再打开目标课程处理验证，登录状态自动记录，关闭窗口后再点击“开始本站学习”继续播放。

华医网遇到打卡或身份验证时会保存进度、暂停当前媒体并等待人工处理，后续视频保持排队。请先暂停本站学习，通过“登录本站”打开目标课程完成人工验证，登录状态自动记录，关闭窗口后继续。

点击视频任务的“查看”可查看验证事件日志。每次事件包含验证类型、触发时间、章节标识、实际播放器进度、平台状态、事件标识及采取的操作。日志分别记录重开页面、再次触发验证、进度重新增长，以及重启失败或被手动暂停的结果。重开后的进度增长只表示播放器恢复，不代表平台已确认打卡或课程完成。

如需学习另一门课，在同一用户的网站设置中点击“添加课程”粘贴学习链接，名称自动从网页提取。先暂停本站播放，再在该课程行读取视频列表。读取结果只归属所选课程；如果页面跳转到了另一门课程，系统会拒绝导入。“开始本站学习”会将本站未移除课程的未完成视频排队。

## 暂停、继续和退出

- **暂停播放：**点击网站设置中的“暂停本站学习”。当前视频和该账号排队中的视频都会暂停，已记录的进度会保留。
- **继续播放：**点击网站设置中的“开始本站学习”，继续处理未完成的视频。实际从哪里继续播放，以平台当前保存的进度为准。
- **退出程序：**建议先暂停正在播放的账号，再回到启动程序的终端按 `Ctrl+C`。
- **再次使用：**运行 `npm start`，打开管理界面，然后点击需要继续学习的网站中的“开始本站学习”。

如果程序意外关闭，重新启动后，未结束的运行任务会显示为“已中断”。此前记录的进度会保留，点击网站设置中的“开始本站学习”可重新排队。

## 查看进度和任务状态

“视频列表”显示每个视频的播放进度、播放器状态和平台状态。正常播放时，每 5 秒读取一次当前页面的播放器属性；视频结束或报错通过播放器事件及时触发检查，暂停或停止时保存实际进度。结束后若平台尚未确认完成，间隔 15 秒再读取页面完成状态，最多等待 30 秒。播放中的采样不刷新页面或向平台发起额外 HTTP 请求，平台播放器原有的学时上报照常运行。华医网视频自然结束后，会单独打开所属课程目录确认目标章节状态，最多每 15 秒一次；只读取该章节的学习状态，不进入考试，也不把目录累计时间当成播放器时间。平台未确认时暂停队列并提示人工检查。

界面可见时大约每两秒刷新本地记录，切到后台后停止自动刷新，可切换用户和网站，并按课程筛选查看。界面刷新不会重新读取平台播放器，进度以显示的采样时间为准。

| 状态 | 含义与操作 |
| --- | --- |
| 待启动 | 已添加视频，点击网站设置中的“开始本站学习”即可排队 |
| 排队中 | 正在等待播放名额，无需重复点击开始 |
| 运行中 | 程序正在处理该视频，可查看播放进度 |
| 等待人工验证 | 先暂停，再通过网站设置的“登录本站”完成验证，登录状态自动记录，关闭窗口后点击“开始本站学习” |
| 已暂停 | 播放已暂停，点击网站设置中的“开始本站学习”可继续 |
| 需要处理 | 播放或平台确认遇到问题，需要先人工检查 |
| 已结束 | 该任务已结束；学时与课程完成情况仍以平台记录为准 |
| 失败 / 已中断 / 已停止 | 查看原因并处理后，点击网站设置中的“开始本站学习”重新排队 |

尚未读取到视频时间或时长时，进度会显示“未知”。本地播放进度用于帮助查看播放情况，不等同于平台累计学时。

“任务记录”用于查看人工登录、页面检查和播放列表读取的结果。点击对应任务的“日志”，可查看执行过程和错误信息。

## 使用多个用户与网站

每个用户分别绑定网站，各网站有独立账号、课程列表、登录资料与任务。按“添加用户 → 选择网站 → 网站设置 → 添加课程”设置即可；随后通过网站设置统一登录，再在课程行读取视频列表。

默认全局同时运行一个任务，其他任务等待空闲名额。同一个网站账号每次只能进行一项操作，例如登录、读取列表或播放视频；重新登录或读取另一门课时请先暂停本站播放。

可按下方设置调整多个账号同时运行的任务数量。两个网站的登录、目录读取和播放都遵守账号互斥与全局并发限制。读取目录本身不会开始播放；点击“开始本站学习”才会将未完成且未排除的视频加入队列。

## 常见问题

### 出现“需要处理”怎么办？

程序会暂停该账号的视频队列并保留进度。先查看视频状态和相关提示，然后：

1. 点击网站设置的“登录本站”，再在网站内打开目标课程。
2. 在浏览器窗口中检查课程页面，完成登录、验证码或其他平台要求的人工操作；如播放器报错，确认页面能正常播放。
3. 进入目标课程播放页，登录状态会自动更新；完成验证后关闭窗口，回到管理界面继续。
4. 点击网站设置上的“开始本站学习”，继续未完成的视频。

播放器错误、播放进度持续 60 秒未增长、要求重新登录或前置学习，或视频结束后平台未明确确认完成，都可能需要人工处理。河南平台打卡提示会先自动暂停并以无头模式重开，短时间重复触发超过上限时等待人工操作；华医网打卡与两个网站的身份验证均暂停当前媒体并等待人工操作。请先暂停该账号，再通过网站设置的“登录本站”处理，登录状态自动记录，关闭窗口后点击“开始本站学习”。等待人工验证的时间不计入 60 秒停滞时限。

### “登录本站”或“读取视频列表”按钮不可用怎么办？

先检查该账号是否有正在运行的任务。有视频在播放时，点击“暂停本站学习”；其他任务正在执行时，等待其结束，或在“任务记录”中点击“停止”。河南平台的“读取视频列表”还需要先完成人工登录，状态自动记录后关闭窗口。华医网会尝试使用该用户已保存的本站浏览器资料读取；如要求登录，请先通过网站设置登录，状态会自动记录。

### 登录状态已保存，为什么仍然要求登录？

平台登录可能已经过期。重新执行网站设置的“登录本站”，在平台完成登录并进入课程播放页后，状态会自动记录，完成后关闭窗口即可。

### 播放列表为空或读取失败怎么办？

通过网站设置的“登录本站”打开网站并确认当前页面是目标课程的播放页，并能看到视频列表，登录状态会自动记录，关闭窗口后重新读取视频列表。若平台页面已变化，可能需要更新程序后再使用。

### 浏览器无法打开怎么办？

确认已经执行 `npm run browser:install`，且电脑有可用的图形桌面。如果修改过浏览器缓存位置，请使用当前设置重新执行安装命令。

### 管理界面打不开怎么办？

确认 `npm start` 的终端仍在运行，并查看终端是否出现错误。默认地址是 [http://127.0.0.1:3000](http://127.0.0.1:3000)；修改过端口时，请使用新端口。若提示端口被占用，可调整下方的 `API_PORT`，然后重新启动。

同一个数据目录只能运行一个 MedCourse 程序。如果提示已有实例正在运行，请先检查并关闭其他启动窗口。

## 按需调整设置

一般使用默认设置即可。需要调整时，用文本编辑器打开 MedCourse 文件夹中的 `.env`，修改后退出并重新启动程序。

| 设置 | 默认值 | 何时修改 |
| --- | --- | --- |
| `API_PORT` | `3000` | 默认端口被占用时，换一个 1～65535 之间的可用端口；访问地址也要随之修改 |
| `MAX_CONCURRENCY` | `1` | 需要多个账号同时运行时，可设置为 1～8；人工登录等操作也占用运行名额 |
| `DATA_DIR` | `./data` | 需要把账号资料和进度存放到其他位置时修改；切换到空目录后不会显示原有资料 |
| `BROWSER_CHANNEL` | `chromium` | 默认浏览器有播放兼容问题时，可尝试 `chrome` 或 `msedge`，对应浏览器需提前安装 |
| `PLAYWRIGHT_BROWSERS_PATH` | 数据目录下的 `browsers` 文件夹 | 需要更改浏览器下载位置时设置，修改后重新执行 `npm run browser:install` |

设置中的相对路径以 MedCourse 文件夹为基准。调整并发数量前，确认电脑资源和网络能够支持多个账号同时运行。

## 保存和备份资料

账号信息、课程任务、进度、日志和浏览器登录资料默认保存在 MedCourse 文件夹中的 `data/` 目录。关闭程序后复制该目录，即可备份；恢复时也应先关闭程序，再放回同一位置。如果修改了 `DATA_DIR`，备份对应的目录。

登录资料包含会话信息，请将备份保存在自己控制的位置。保留数据目录即可在下次启动时继续使用已有账号和任务。

## 从单网站版本升级

退出原服务后，更新代码并执行 `npm run build`，再执行 `npm start`。首次打开旧数据库时，程序自动在同目录保存 `medcourse.sqlite.pre-v3-时间戳.bak` 备份，然后迁移到多网站结构。

每个旧账号会对应一位同名用户，并绑定河南平台；原有多门课程按任务中的课程地址分别恢复。账号和任务 ID、进度、日志及浏览器目录保留，同名账号不会自动合并成一个用户。仅保存过平台首页的账号不会创建空课程，可以自行添加。

迁移不会自动开始旧队列，请在网站设置中手动继续。自动备份只包含数据库；完整备份仍应在停止服务后复制整个数据目录。如需退回旧版，先停止新版，再恢复迁移前数据库及对应资料，不要直接让旧程序读取升级后的数据库。
